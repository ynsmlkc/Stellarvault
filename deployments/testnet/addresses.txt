The factory deploys one `vault-instance` contract per vault (Safe-style), so a
vault's address is minted at create time — there is no single "vault contract"
to list here. `factory.get_vaults(owner)` is the on-chain registry.

### vault-instance WASM

v2 (guards)  = c2428442e3d668f301a7b1ce5fb40eac884ddd448d6df9a5c1cce2ebbaf45c9b
               uploaded 2026-07-30; factory.set_wasm applied the same day

v2 adds the owner-configurable Policy (per-tx limit, rolling spending cap,
time-lock, recipient allowlist), batch/multi-call proposals, typed contract
errors, proposal cancellation and an owner-gated `upgrade`.

NOTE: `set_wasm` only affects vaults created AFTER it. Vaults deployed on v1
have no `upgrade` entry point and therefore stay on v1 permanently — the
frontend detects this (no `version()`) and renders them without guards.
